# 主积分改用 Bradley-Terry 强度，综合分转为验证基线

## 动机

单一全局总榜是硬需求；现行 Copeland 胜率按各自对手池计算，覆盖率不同导致赛程不可比，弱的低覆盖模型可能压过强的高覆盖模型。需要在不拆榜的前提下，用统计上可解释、权威的强度估计替换胜率，并把现行综合分保留为验证/诊断，而不是混合进主分。设计决策见 `docs/adr/0015-PK-主积分改用-Bradley-Terry.md`。

## 涉及能力

- `ranking`：主积分公式、排名、前沿、对比、CSV 与证据说明。
- `share-link`：不新增或不改变参数；现有 `cm` 来源组合对照保留。
- `history`：无行为变化（历史抽屉仍展示原始源数据）。

## 行为变化

- `analyze` 继续使用现有 `majorityMatch` 对局；新增 Bradley-Terry MAP 拟合（`Gamma(2,1)` 先验、平局半胜、MM 确定性迭代），输出：
  - `composite`：Elo 风格 BT 等级分 `1000 + 400/ln10 × (θ − median θ)`；
  - `winRate`：现行 Copeland 胜率，仅作诊断；
  - `theta`/强度字段供对比页与 CSV 复算；
  - `record`、`auxiliary`、成本、覆盖率、对手数不变。
- 主积分使用 Elo 尺度，不保留 0-100 主积分展示；`auxiliary` 的 0-100 是独立统计量，只用于同分排序，不得与主积分混读。
- 主榜仍为单一全局榜，按 `composite` 排名；`auxiliary` 仍只在主积分同分时排序；前沿与支配使用 `composite`；`winRate` 不进入主分、先验、前沿、同分排序或分享参数。
- 对局图连通性门槛：不连通时不赋全局 `composite`/名次，返回明确原因；不按先验硬连。
- `coverageCohorts` 的来源组合对照改用 BT 计分；默认组合、覆盖模型数和对照说明不变。
- 对比/证据页新增“方法对照”：并列展示 BT 名次/等级分与现行综合分名次/胜率、对手数、共同有效榜覆盖；说明两者同源、分歧不代表谁对，低覆盖模型差异通常更大。主榜不加诊断列。
- CSV：`PK主积分` 为 BT 等级分；新增 `BT强度θ`、`现行综合分（Copeland）`、`现行综合分名次`、`名次差`；保留胜平负、对手数、共同榜分布、位次均值、前沿列；评分公式/口径文案更新为 BT + Elo 尺度，并声明不是实测胜率、能力比例或置信区间。
- FAQ/评分说明/README：更新 PK 主积分定义、Elo 尺度、平局半胜、先验、连通性、诊断列和“不宣称更准”的边界。
- 分享链接：不编码分数或公式版本；`cm` 继续表示来源组合对照；旧链接按当前唯一规则计算。
- 历史抽屉、成本口径、源站抓取、刷新/巡检不变。

## 兼容与影响

- 分数数值、名次、前沿成员、对比页/CSV/E2E 文案会变化；原始数据、成本、分享参数、历史归档不变。
- 主积分 0-100 展示尺度不再保留；这是有意的语义变更，避免把相对强度误读为胜率。
- 不保留旧 Copeland 主积分模式；`winRate` 只作为诊断保留。
- 不迁移历史数据；不改变来源巡检/CI 夹具。
- 若连通性失败，主榜明确不可用，而不是回退到旧公式。

## 验收要点

- 单测覆盖：两模型已知 BT 解、三模型循环、软赛程（弱模型刷弱对手不高于强模型）、全胜/全败有限、平局半胜、行顺序不变、连通性失败、CSV 新列、`coverageCohorts` BT。
- 留一榜验证作为回归基线；时间回测（历史快照 t 拟合、t+1 预测）作为“更准”的验收门槛；未通过前不宣称准确率提升。
- E2E：融合榜/前沿/对比/CSV/分享恢复；主榜仍为单表；方法对照在对比/证据页可见。
- `npm run test:coverage`、`npm run build`、三套 E2E 全绿。
