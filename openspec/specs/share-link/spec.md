# 规格：分享链接（share-link）

当前系统行为。契约决策见 `docs/adr/0002`。

## ADDED Requirements

### Requirement: 完整口径状态编码

页面锚点含 `?` 时，`?` 之后的查询串表示完整评分与显示口径（估算与历史排除开关、成本口径、预算筛选、排行榜与前沿探索的显示筛选、对比选择）。

#### Scenario: 往返保持一致

- **WHEN** 任意合法口径状态经 encode 后再 decode
- **THEN** 得到与原状态等价的口径

#### Scenario: 探索页显示状态可复现

- **WHEN** 链接带 `cr=<厂商>` 或 `of=1`
- **THEN** 前沿探索按该厂商 / 仅看前沿渲染，同一链接复现同一列表；两者为默认值时不出现在链接中

#### Scenario: 默认值不写入链接

- **WHEN** 全部有效口径均为默认值时生成链接
- **THEN** 分享链接保留空查询标记（如 `#overview?`），使默认口径也完整恢复；手动打开无 `?` 的普通页面地址仍沿用本地偏好

### Requirement: 非法输入不破坏页面

#### Scenario: 非法值被丢弃

- **WHEN** 查询串包含过时评分参数、未知枚举或非有限预算
- **THEN** 对应项回落默认值，页面正常渲染

#### Scenario: 多个问号与空白

- **WHEN** 参数串中出现第二个 `?` 或编码空白
- **THEN** 仅以第一个 `?` 分割页面名与参数，空白经编码后可往返

### Requirement: 只分享当前设置

#### Scenario: 不再复现旧公式

- **WHEN** 地址携带 score、p、w 或 ms
- **THEN** 忽略这些参数，按当前唯一规则计算；encode 不再写入这些参数

#### Scenario: 当前设置往返

- **WHEN** 分享成本、质量排除、估算、预算、显示筛选与模型选择
- **THEN** 重新加载与同文档恢复使用相同设置和当前唯一评分规则，不需要公式版本标记
