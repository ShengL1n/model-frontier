# 规格：分享链接（share-link）

当前系统行为。契约决策见 `docs/adr/0002`。

## ADDED Requirements

### Requirement: 完整口径状态编码

页面锚点含 `?` 时，`?` 之后的查询串表示完整评分与显示口径（权重预设、最低覆盖、估算与历史排除开关、成本口径、预算筛选、排行榜与前沿探索的显示筛选、对比选择）。

#### Scenario: 往返保持一致

- **WHEN** 任意合法口径状态经 encode 后再 decode
- **THEN** 得到与原状态等价的口径（自定义权重保留小数精度）

#### Scenario: 探索页显示状态可复现

- **WHEN** 链接带 `cr=<厂商>` 或 `of=1`
- **THEN** 前沿探索按该厂商 / 仅看前沿渲染，同一链接复现同一列表；两者为默认值时不出现在链接中

#### Scenario: 默认值不写入链接

- **WHEN** 全部口径均为默认值时生成链接
- **THEN** 锚点仅含页面名（如 `#overview`），无 `?` 参数

### Requirement: 非法输入不破坏页面

#### Scenario: 非法值被丢弃

- **WHEN** 查询串包含越界权重、未知预设或非有限预算
- **THEN** 对应项回落默认值，页面正常渲染

#### Scenario: 多个问号与空白

- **WHEN** 参数串中出现第二个 `?` 或编码空白
- **THEN** 仅以第一个 `?` 分割页面名与参数，空白经编码后可往返
