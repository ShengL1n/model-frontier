# 规格：融合评分与前沿（ranking）

当前系统行为。口径基准见 `docs/adr/0003`。

## ADDED Requirements

### Requirement: 排名分计算

各启用榜单按原始分降序排名（并列取平均名次），`排名分 = 100 × (N − r) / (N − 1)`；按预设或自定义权重算术平均得到综合分，单一模型记 50。

#### Scenario: 严格口径

- **WHEN** 仅纳入对全部启用榜单均有有效分的模型
- **THEN** 所有模型在同一基准样本上计分

#### Scenario: 探索口径

- **WHEN** 允许不完整覆盖（至少 X 榜）
- **THEN** 缺失榜单不补零，已有权重重新分配；页面明确提示比较依据不同

### Requirement: 显示筛选不影响评分

#### Scenario: 筛选只改显示

- **WHEN** 应用搜索、厂商、开放状态或预算筛选
- **THEN** 分数、名次与前沿成员与筛选前完全一致

### Requirement: 帕累托前沿

不存在另一模型成本不高、分数不低且至少一项更优时，模型属于前沿；全球前沿与仅开放权重的前沿分别计算。

#### Scenario: 成本缺失不入图

- **WHEN** 模型成本缺失、为零或非正
- **THEN** 该模型不进入对数成本图与前沿判定

### Requirement: 厂商快捷筛选

模型表上方的厂商 chip 与「全部厂商」下拉同源于 creator 字段，只改变显示，不影响分数、名次与前沿成员。

#### Scenario: chip 与下拉等价

- **WHEN** 点击某一厂商 chip 或在下拉中选择同一厂商
- **THEN** 列表结果一致；再次点击已激活 chip 取消筛选

#### Scenario: 计数取当前视图完整行池

- **WHEN** 切换融合总榜 / 单榜 / 前沿探索视图
- **THEN** chip 计数与同行下拉的选项池同口径，不被搜索、开放状态提前裁剪；0 命中置灰，但已激活的 chip 永不置灰（必须可取消）

### Requirement: 证据提示列

融合排行榜「数据提示」列只渲染条件性证据标签（估算、历史配置、来源被排除或抓取失败），无标签时留空；配置一致性徽标只在模型详情与对比页的「配置一致性与数据提示」展示；前沿探索的模型表不设该列。

#### Scenario: 排除来源有点对点提示

- **WHEN** 某来源被质量开关排除
- **THEN** 排行榜该列出现「<来源> 已排除」标签，抽屉给出逐源明细与原因

### Requirement: 被支配区跟随鼠标

前沿图中悬浮任一全球前沿模型，即标出它同时以更低成本、更高综合分支配的区域。

#### Scenario: 悬浮前沿模型出区域

- **WHEN** 鼠标悬浮某一全球前沿模型（散点或前沿连线上的点）
- **THEN** 画出该模型右下方至轴缘的矩形，并注明「被 X 支配 · N 个模型」，N 为区域内被严格支配的模型数

#### Scenario: 点对点迁移与撤下

- **WHEN** 鼠标从一前沿模型直接移到另一前沿模型、移到画布空白或关闭「全球前沿」图例
- **THEN** 区域改画新锚点、延迟撤下或随图例隐藏，不残留旧区域
