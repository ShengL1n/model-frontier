# ADR-0016：主榜最低有效对手门槛

- 状态：已接受
- 日期：2026-10-20
- 授权：用户要求按“真实中位模型进入前 20 的概率 ≤5%”的标准选择阈值并落地；主榜取 10 个有效对手。

## 背景

ADR-0015 的 BT 与 Gamma(2,1) 先验降低小样本偏差，但没有最低证据门槛。当前快照中 1 胜 0 负的模型最高只能到第 14 名（Elo 1332.7），不进入前 10；但在更稀疏的图结构下，1 场全胜可以排到第 1。需要一个可解释、可复核的主榜准入规则，避免低样本模型因偶然全胜进入高位。

## 决策

1. 主榜全局排名要求 `record.opponents >= 10`；对手数按双方共同至少两榜的对局计算。
2. BT 拟合仍使用所有有效对局，包括低样本模型的比赛；低样本模型只是不获得主榜 `composite`、`theta`、`btRank`、`copelandRank` 和前沿身份，不从拟合中删除，以免损失对手强度证据。
3. 低样本模型保留原始分、配置、胜平负、`winRate`、对手数和辅助位次均值；表格显示“证据不足”原因，CSV 的 `PK主积分`、`BT强度θ`、`名次差` 留空。
4. 连通性门槛先于对手数门槛；对局图不连通时仍不给出全局名次。
5. 来源组合对照是诊断层，不套用主榜 10 对手门槛；表内保留组内对手数，并说明不能替代主榜。
6. 10 的选择依据：参数化模拟（当前 87 个有分模型、3141 场对局、14% 平局；新模型真实强度取中位，对手均匀随机；每个 k 做 500/1000 轮）显示真实中位模型进入前 20 的概率：

   |   k |  前 20 概率 |
   | --: | ----------: |
   |   1 |   7.6%–8.9% |
   |   2 | 12.2%–13.2% |
   |   5 |   6.0%–6.1% |
   |   7 |   3.4%–4.9% |
   |  10 |   2.0%–3.3% |
   |  20 |   0.3%–0.8% |

   前 10 概率在所有 k 下为 0%。7 是首个接近 5% 的值，但区间跨 5%；10 有保守余量，且当前快照最少 20 个对手，所以不改变现有榜单。

7. 边界：模拟依赖当前图、均匀赛程和 14% 平局率假设，不是置信保证。10 胜 0 负仍可能高位（若胜前 10 对手，模拟约第 4）；这是实质证据，门槛只控制中位模型的误入率。时间回测仍未执行，不宣称准确率提升。

## 影响与兼容

- `analyze` 默认 `minOpponents=10`；新增 `requiredOpponents` 与每行 `rankEligible`。低样本行的 `composite`、`theta`、`btRank`、`copelandRank` 为空，`reason` 说明“有效对手不足 10（当前 N）”。
- 主榜、概览、前沿、对比方法对照、CSV 与分享恢复同步；来源组合对照保持不变。
- 原始数据、成本口径、历史归档和分享参数不变；无数据迁移。
- 当前快照所有有分模型都有至少 20 个对手，现有名次、分数和前沿成员不变。
- 回滚：移除门槛，恢复全样本主榜排名。

## 验证

- 单测：1 个对手的模型不获主榜名次；10 个以上对手正常排名；低样本模型的对局仍进入 BT 拟合；默认门槛与显式覆盖；连通性优先；CSV 空列与原因；来源组合对照不受影响。
- 现有快照回归：所有有分模型仍排名，数值不变。
- `npm run test:coverage`、`npm run build`、三套 E2E。
