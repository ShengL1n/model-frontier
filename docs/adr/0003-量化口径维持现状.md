# ADR-0003：量化口径维持「名次百分位 + 算术平均」

- 状态：已接受
- 日期：2026-10-16（追溯记录既有决策，作为后续变更的基准）

## 背景

融合评分可选名次百分位法、几何平均能力分、sigmoid 压缩等多种口径。

## 决策

维持现状：

- 各榜按原始分降序取名次，`排名分 = 100 × (N − r) / (N − 1)`，按权重算术平均。
- 综合相对成本用三站成本对中位数比值的**等权几何平均**（完整三源各 1/3，缺一源取两比值平方根）。
- 不引入几何平均能力分（存在清零硬伤：任一榜单无分即全盘归零）、不引入 sigmoid 压缩。

## 后果

- 名次法舍弃原始分差，这是已知的、README 明示的取舍，不是缺陷。
- 任何口径变更（含新增「均衡镜头」类派生列）必须先修订本 ADR 并经 owner 点名。
