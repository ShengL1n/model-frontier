# ADR-0013：Arena 作为第四个评分来源

状态：接受，2026-10-19。补充 ADR-0011、0012。

## 决策

纳入 Arena 官方 Hugging Face 数据集 `lmarena-ai/leaderboard-dataset` 的 `text / latest / overall`，通过后台 HTTP 下载官方 text/latest Parquet 单文件快照，不使用浏览器。Arena 提供人类盲测偏好证据，不宣称纯客观能力，也不将其所有分类重复计票。

AA、Vals、LiveBench、Arena 每来源一票；仍至少两榜有效分准入、双方至少两榜共同有效才比赛。四榜 2:2 判平，单榜原始同分平票；不使用原始分差裁决平局。最终主积分相同时使用有效来源排名百分位等权平均辅助排序。Arena 分数、票数、区间、配置和发布日期可核对，区间仅为 Arena 源站区间，不是融合置信度。

Arena 无任务成本，不加入成本来源、美元预算或成本几何平均。现有三站成本定义与帕累托支配规则不变；主图继续复用融合主积分。

## 影响与风险

加入来源会改变准入样本、对手集合、主积分及辅助分，排名变化不代表模型能力随时间改变。旧 Arena 缓存不能作为新接口的成功观测使用，须重新获取。快照必须完整且同一发布日期，缺字段、缺总榜、重复行、下载或解码中断明确失败，沿用最近一次成功缓存并显示原因。历史记录只从真实获取开始。

来源数量不等于独立证据数量；其他榜单需核对独立性、测试范围、当前更新与可获取性后再纳入，不把同一托管平台或重复子榜算作独立票。

## 获取方式验证

2026-10-19 实测：官方单文件快照 613695 字节，11033 条分类记录，筛出 416 条 overall 配置，发布日期 2026-10-15。JSON rows 接口可访问，但 filter 接口多次 500 / 超时；因此下载一次官方 Parquet，使用纯 JavaScript、无运行时依赖的 hyparquet 解析，避免每次 111 个分页请求或引入 Python 服务。新增依赖仅服务端使用。
