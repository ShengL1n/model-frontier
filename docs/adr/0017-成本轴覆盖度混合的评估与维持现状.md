# ADR-0017：成本轴覆盖度混合的评估与维持现状

- 状态：已接受（评估后维持 ADR-0003 现行成本口径，不改代码）
- 日期：2026-10-26
- 授权：用户提出「新模型成本远大于旧模型，按理说不该影响旧模型」，要求复核并选择最合适方案；约束是保持单一总榜、不引入多维度，且综合成本是特意设计的口径、不换成单源，同时不接受丢掉可用数据源。

## 背景

用户观察到「发布新模型后旧模型被从帕累托曲线剔除，但新模型成本远大于旧模型」。对 23 个历史快照全量复算后的结论：

1. **帕累托判定本身正确。** `pareto()` 要求支配者「成本不高且分数不低」，更贵的新模型在数学上不可能支配更便宜的旧模型。5 次跌出前沿的支配者 100% 是「上期已在前沿的老模型」，没有一次是新进入者。
2. **纵轴漂移合理且不可消除。** 主积分是 BT 强度，`1000 + (400/ln10)×(θ − 池中位θ)`（ADR-0015）。中位数平移对所有模型是同一常数——实测把纵轴换成原始 θ 重算，前沿集合与用 Elo 分完全一致，故中心化不影响前沿成员。真正的前沿变动来自重新拟合，新对局就是关于旧模型的新信息，这是评级体系的设计目的。23 个快照中唯一一次「自身与支配者数据均未变」的跌出（10-19 GPT-6.1 Sol，成本 59.53→59.53 未动，分数 1503.9→1466.4）纯由重新拟合造成。
3. **横轴存在真实但有限的缺陷。** 综合相对成本按池中位数归一，却只对每个模型**自己有的**来源取几何平均。全 3 源模型的指数漂移完全一致（10-22 实测 16 个模型一律 +21.33%，极差 0.00pp），2 源模型的漂移取决于缺哪一个源（同一次 2 源组极差 55.13pp）。算术来源：全源模型漂移 = 三个中位数对数变动的均值，缺源模型只平均它有的那些源，而三个中位数各自变动幅度不同（合成测试中 aa +30.07%、vals +3.14%、livebench +15.97%）。

   真实影响实测（23 个快照逐对重算，组分覆盖度的平均指数漂移之差）：

   | 指标                   | 值                                            |
   | ---------------------- | --------------------------------------------- |
   | 平均组间漂移差异       | 0.92pp                                        |
   | 最大组间漂移差异       | 8.57pp（2026-10-16：3 源 +0.1% / 2 源 −8.5%） |
   | 单独导致跌出前沿的次数 | 0                                             |

   10-16 那次 DeepSeek V4.1 Flash 跌出（自身数据未变、指数 +3.9%）中，成本漂移与支配者 MiMo V2.6 Pro 自身数据变化共同促成了结果，但不是唯一原因。

## 决策

**维持 ADR-0003 现行成本口径不变**：默认仍允许至少两源成本，缺一源取两比值平方根并标记 2/3；默认 `costSource` 仍为 `"composite"`。唯一交付是把上述机理与实测幅度写进 README 的成本口径段与 FAQ，让「跌出前沿」可被解释，并新增一条全源池的性质回归测试。

## 理由

根因是「一个成本轴上混合了不同覆盖度的度量」。修复必须让轴上每个点按同一把尺子度量。五条候选路经全部实测：

| 方案                              | 今天前沿      | 合成压力测试（加入贵 10 倍新模型） | 组间漂移差异              | 可绘图模型 | 结论                 |
| --------------------------------- | ------------- | ---------------------------------- | ------------------------- | ---------- | -------------------- |
| 现状                              | 6             | Kimi 被挤走                        | 平均 0.92pp / 最大 8.57pp | 31         | 基准                 |
| A 缺失源插补完整样本比率几何均值  | 6（成员大变） | 无人被挤走                         | 平均 1.13pp / 最大 7.91pp | 31         | 否决                 |
| A′ 缺失源插补全部披露样本几何均值 | —             | —                                  | 平均 1.34pp / 最大 6.92pp | 31         | 否决                 |
| C 综合指数只收全源                | 5             | 无人被挤走                         | 0                         | 17         | 否决（用户判定过苛） |
| D 中位数基准冻结                  | 6（不变）     | 无人被挤走                         | 0                         | 31         | 否决                 |
| F 默认横轴改 AA 绝对美元          | 9             | 无人被挤走                         | 0（无中位数）             | 75         | 否决                 |

- **A/A′ 不精确。** 插补项必须随中位数同比变动才能对齐漂移，而几何均值对样本构成变化比中位数敏感得多：实测组间差异平均 1.13pp / 1.34pp，比现状的 0.92pp 还差。合成极端测试（加入 10 倍成本模型）下更从 2.5pp 恶化到 6.9pp。数学上，插补项要么不随中位数动（填中性项），要么随中位数的同时随样本构成动（填几何均值），无法严格对齐。
- **C 精确但过苛。** 可绘图 31→17，前沿丢掉 MiMo V2.6 Flash（全榜最便宜、开放权重）与 Muse Spark 1.3，廉价一端只剩 GPT-6 Luna（Elo 862）——它上前沿只是因为更便宜的模型被排除。为一个平均 1 个百分点、从未单独导致跌出的噪声丢掉 14 个有真实成本数据的模型，用户判定不划算，同意。
- **D 精确但在这个数据环境活不久。** 冻结基准能让每个模型的指数只随自身成本变动，是唯一「保留全部模型又精确」的路；但三源完整样本单日就能让中位数动 21%（10-22 实测），冻结基准几周内就会让「1.0 = 典型」失真，需要频繁重新钉基线，与「小工具、不追求长期演化」冲突。且基准是从数据测出来的量，冻进代码是数据进代码。
- **F 方法论不成立。** 同一模型三源任务成本中位相差 6.53 倍（最小 3.43×，最大 14.90×；Claude Haiku 5.5 为 0.213 / 3.170 / 0.632），三源量的不是同一件事。AA 覆盖 75/84 只是抓取广，不是方法论理由；综合成本按各源中位数归一再取几何平均，正是 ADR-0003 为消掉源间差异特意设计的。
- **显示层已充分披露**：每个模型标明 2/3 或 3/3，模型详情可复算中位数与每站明细，README 原已写明「部分覆盖仍有任务分布偏差」。本次只补足实测幅度与FAQ 解释，不新增维度、不改任何分数、名次、前沿规则或分享契约（宪法第 2、3、5 条均不触及）。
