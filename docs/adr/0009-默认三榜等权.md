# ADR-0009：默认采用三榜等权

- 状态：默认评分已被 ADR-0010 替代；保留为权重决策的历史记录
- 日期：2026-10-19
- 授权：用户要求重新评估调研后给出的权重，不合理则修改。

## 依据与判断

AA 当前综合通用、科学推理、编程与 Agent 评测；Vals 是按美国行业 GDP 加权的金融、编程、法律与税务任务指数；LiveBench 2.0 是七类任务等权均值，含截图浏览器操作，且无法完成或重复故障任务可计零。三者都有任务覆盖与协议局限，部分编程和 Agent 信号重叠。

官方来源（2026-10-19 核对）：

- https://artificialanalysis.ai/methodology/intelligence-benchmarking
- https://www.vals.ai/benchmarks/vals_index
- https://livebench.ai/#/methodology

目前没有独立目标任务集、泛化验证或各榜误差协方差，无法从上述差异推导出 AA 40%、Vals 35%、LiveBench 25% 是经过优化的比例。原「能力优先」命名暗示了未经证明的优势。

## 决策

1. 默认采用三榜等权，各占 1/3。这是无外部校准时的简单基线，不声称最优、独立或消除了评测偏差。
2. 撤下所有非等权预设（capability、objective、broad），不以「侧重」换名保留。历史比例只用于旧链接兼容，界面不可选择推荐。用户手动调权仍作为自定义，明确由其输入。
3. 本地非自定义旧预设迁移到 equal；保留自定义。旧链接直接解码，绕过本地迁移。
4. 旧分享链接的 capability 及缺省 p 仍解释为原 40/35/25。equal 链接显式编码 p=equal。应用无分享参数时使用新默认；有参数的旧链接仍使用旧协议默认。避免破坏第三方复现。
5. 名次百分位、加权算术平均、缺榜重分配及成本算法不变。源站有效零分继续保留，不为特定模型改分或删项。

## 后果

默认排名可能改变，包括 GLM 5.3 与 DeepSeek V4.1 Flash。不能用某对模型的先后来证明方案优劣。新增权重优化必须先定义独立目标与验证方法，不能按当前榜单倒推权重。

本 ADR 补充 ADR-0003 关于权重预设的决策。

## 原始分与排名分复核

直接平均原始分需要三榜分值具有可比的单位与间隔。均为百分制不满足该条件：AA 是多任务复合指标，Vals 带经济行业权重，LiveBench 的七类任务含输入能力限制及故障零分。没有共同校准样本，暂不采用原始分直接平均。继续使用对单榜严格单调变换保持不变的排名百分位；明确其只表达相对位置，舍弃原始分差，不是能力百分比。原始分仍逐榜展示，不隐藏。

撤掉三套任意权重的敏感性比较。保留固定三榜等权下四种既有成本口径的前沿入选率（4 场景），改称成本敏感性；它只描述成本口径影响，不代表统计置信度。
