# ADR-0001：Node 前后一体单服务，不分离不换栈

- 状态：已接受
- 日期：2026-10-16（追溯记录项目创立决策）

## 背景

本页面需要一个本地服务做三站数据抓取、缓存与回退，同时托管 React 前端。可选方案：前后端分离部署、引入 Express/Nest 等框架、静态化纯前端。

## 决策

单一 Node 进程（`server/index.mjs`，原生 `node:http`，零后端框架）同时提供 `/api/*` 与构建后的静态资产；Vite 只负责打包。前后端同仓同进程，共享 `src/` 下的纯函数模块（`analysis.mjs` 等可被单测直接导入）。

## 后果

- 部署即 `npm start`，双击启动器可用；仅监听 127.0.0.1。
- 换来简单，代价是扩容、多用户能力为零——这正是本项目的非目标。
- 任何「分离 / 换栈 / 加框架」提案默认拒绝，除非 owner 推翻本 ADR。
