# ADR-0012：仅保留当前评分规则

- 状态：已接受
- 日期：2026-10-19
- 授权：用户明确说明自用，不需要旧三榜链接复现能力。

删除旧百分位加权主分、三榜 v1、旧预设、调权与覆盖兼容控件、公式版本切换及偏好备份逻辑。唯一规则维持 ADR-0011 的两榜准入、共同至少两榜才比赛、主积分同分按等权排名百分位辅助排序。帕累托仍只使用主积分和成本。

分享继续支持当前质量排除、成本、预算、页面筛选与模型选择；不再编码或解析 score/p/w/ms。旧链接中的这些参数不再具有语义，统一按当前公式计算。导出仅标明当前计算规则与战绩，不承诺历史公式复现。已存在的历史数据快照、源站版本记录及本地备份不做删除，本次只撤除评分兼容代码。

本 ADR 替代 ADR-0010、0011 中旧公式兼容与版本化要求，不改变当前实际排名结果。
