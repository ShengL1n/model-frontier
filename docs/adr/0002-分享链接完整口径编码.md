# ADR-0002：分享链接把完整口径状态编码进 URL hash

- 状态：已接受
- 日期：2026-10-16（追溯记录既有契约）

## 背景

页面有大量可调口径（权重预设、覆盖门槛、估算开关、成本口径、预算筛选、排行榜筛选、对比选择）。结论复核要求「打开链接 = 进入完全相同口径」。

## 决策

全部口径状态编码进页面锚点（如 `#rankings?p=equal&ms=3`），规则：

- hash 中含 `?` 即完整口径状态；缺省参数一律等于默认值，默认值不写入链接（保持地址短）。
- 非法值丢弃而不破坏页面；只取第一个 `?` 作为页面与参数分隔符。
- 复制链接时按当前状态即时构造，不依赖去抖后的地址栏，避免复制到上一刻口径。

## 后果

- 服务端零状态即可复核；导出 CSV 另附数据时间与口径列，双通道互为备份。
- 新增任何影响结论的口径时，必须同步进 `src/share.mjs` 的编解码与 `tests/share.test.mjs` 的往返测试。
