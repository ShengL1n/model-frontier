# ADR-0015：PK 主积分改用 Bradley-Terry 强度

- 状态：已接受
- 日期：2026-10-20
- 授权：用户要求单一全局总榜，确认主榜采用 Bradley-Terry、现行综合分仅作验证基线与分歧诊断，不做加权混合。

## 背景

现行主积分是 Copeland 多数对决胜率：每个模型对各自实际对手计算（胜 + 0.5 × 平）÷ 对手数。对手集合与共同有效榜数随模型覆盖变化，分差与赛程强度不进入计算。同一份快照中，高名次模型可能在所有共同榜都输给低名次模型（当前 27 对）；低覆盖模型因对手池不同被系统性高估或低估。用户要求保留单一全局总榜，因此不能按覆盖组分榜，也不能把旧分数与新分数按任意权重混合。

## 决策

1. 输入不变：沿用 `majorityMatch` 的现有对局规则（每榜一票、双方共同至少两榜、2:2 平），一场对局一个观察；不引入原始分差。
2. 模型：Bradley-Terry，`P(i 胜 j) = s_i / (s_i + s_j)`，`s_i = exp(θ_i)`；平局按半胜处理，与现行 0.5 计分一致。
3. 估计：对 `s_i` 加 `Gamma(2,1)` 弱先验，用 MM 迭代求 MAP；更新式 `s_i = (W_i + 1) / (Σ_j 1/(s_i+s_j) + 1)`，等价于各加 1 个伪胜场与 1 个伪对手；确定性、无新依赖；收敛阈值 1e-13、最多 2000 轮。先验只用于保证全胜/全败模型强度有限，不按模型覆盖或新旧调参。
4. 显示：Elo 风格等级分 `R_i = 1000 + (400 / ln 10) × (θ_i − median θ)`；中位模型 1000，400 分差约等于 10:1 预测胜率。主积分为该等级分；不保留 0-100 主积分展示。`auxiliary`（榜单位次均值）仍是独立的 0-100 统计量，只在主积分同分时排序，不得与主积分混读。
5. 连通性：对局图必须连通；不连通时不给出跨组件全局名次，明确提示原因，不用先验硬连。
6. 不混合：现行 Copeland 胜率保留为 `winRate` 诊断值及对照名次，只用于对比/证据页、CSV 和方法分歧阅读；不进入主积分、先验、前沿、同分排序或分享参数。
7. 来源组合敏感性对照的组内积分同步改用 Bradley-Terry；主榜保持单一全局。
8. 置信度：不展示置信区间；对手数、共同有效榜数和低覆盖提示继续作为证据深度展示。BT 分数不是实测胜率、能力比例或统计置信度。

## 理由

- 单一全局 + 赛程校正：BT 按对手强度给每场对局加权，消除“软赛程刷胜率”；Copeland 做不到。Colley 在本快照上把 20/36 场的稀疏高胜率模型排到前二（评级超过 100），不适合。
- 权威性：Bradley-Terry 是 1952 年 Biometrika 的成对比较标准模型；LMArena/Chatbot Arena 的评分以 BT 为统计基础，Elo 是其常用展示尺度。
- 可解释性：Elo 分差直接对应预测胜率；原始胜平负、对手数和逐榜分差继续保留；模型只有一层潜变量，无黑箱。
- 不保留 0-100 主积分：BT 输出的是相对强度，不是胜率。0-100 会被读成百分比/胜率；改成新的归一化指数只是换了一个任意尺度，失去 Elo 分差的标准解释。中位 1000、400 分≈10:1 与 LMArena 的 Elo 风格展示一致。
- 当前数据：全榜压制倒挂 27→11，直接对话倒挂 82→64；Claude Haiku 5.5 / Gemini 3.8 Flash、MiniMax-M3.1-Flash / Inkling 两处倒挂修复。留一榜 AUC 为混合结果（BT 0.732 vs Copeland 0.728），因此本 ADR 不宣称“预测更准”，只宣称“消除赛程结构偏差、提升可解释性与权威性”。准确率提升需时间回测验证。
- 不选在线 Elo（顺序/K 值依赖）、TrueSkill/Glicko（复杂度和不确定性建模当前不需要）、Massey/Keener/Kemeny/Borda（需要分差、复杂度过高或覆盖偏差）。

## 影响与兼容

- `analyze` 的 `composite` 改为 Elo 风格 BT 等级分；新增 `winRate`（Copeland 诊断）与 `theta`/强度字段。`record`、`auxiliary`、成本、覆盖率、来源组合对照结构保留。
- 排名、前沿、支配关系、对比页、CSV、FAQ/README、E2E 文案随之更新；主榜仍为单一全局榜。
- 原始数据、成本口径、分享链接参数、历史归档、来源巡检不变；分享链接继续按当前唯一规则计算（ADR-0012），不保留旧公式版本。
- 历史值不迁移；历史抽屉展示原始源数据，不展示 BT 历史分数。
- 若对局图不连通，页面明确提示无法给出全局强度；这是数据质量门槛，不用先验伪造跨组件顺序。

## 验证

- 单测：两模型已知 BT 解、三模型循环、软赛程夹具、全胜/全败有限性、平局半胜、行顺序不变性、连通性失败、CSV 字段。
- 留一榜验证：每次留一榜拟合、预测被留榜两两胜负，比较 BT 与 Copeland 的 AUC；当前结果混合，作为回归基线而非“更准”证明。
- 时间回测：用历史快照 t 拟合、预测 t+1 的对局，比较 log-loss/AUC；作为“更准”的验收门槛。未通过前不对外宣称准确率提升。
- E2E：融合榜、前沿、对比、CSV 和分享恢复。

## 回滚

代码回退到 Copeland；无数据迁移，原始快照与历史归档不受影响。旧链接不保留公式版本（ADR-0012 的自用前提）。
