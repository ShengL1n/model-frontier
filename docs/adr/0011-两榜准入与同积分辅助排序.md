# ADR-0011：两榜准入与同积分辅助排序

- 状态：已接受
- 日期：2026-10-19
- 授权：用户要求至少两榜准入，并明确选择「最终对决积分相同，再按辅助分排序」。

## 规则

新公式版本 majority2：至少两榜有效分的模型进入候选样本；每对模型仅使用双方共同有效的榜单，各榜一票。共同榜单少于两个则不比赛，不算失败或平局，不进入分母；票数相同仍各计半场。主积分 = 100 ×（胜场 + 0.5 × 平场）÷ 实际有效对手数。无有效对手不赋分。

最终排名先按主积分降序；完全相同时，按等权排名百分位辅助分降序。辅助分按整个候选样本中各榜有效分计算该榜排名百分位，再对模型已有的至少两榜排名分等权平均。辅助分只用于主积分完全相同时排序，不改变对决胜负、不加到主积分中。主辅分均相同保留并列名次；名称仅用于稳定展示。

不能把三家原始分直接相加。辅助分的缺榜平均仍有比较依据不同的限制，不解释为能力比例或统计显著性。不同模型的有效对手集合可能不同（当前两榜模型组合之间有仅一榜交集的情况），页面展示实际对手数及不足票的对决，并明确可比性弱于完整三榜样本。

## 前沿与分享

主帕累托图直接复用主排行榜同一次 analyze 的 rows，以主积分和所选成本判断支配；辅助分不参与纵轴、连线或支配判断。同积分时较便宜者可支配较贵者，不按辅助分改变该事实。显示筛选不重算任何分数或前沿。成本敏感性是独立的固定完整成本样本对照，必须明确其重算范围。

新链接 score=majority2，固定 p=equal、覆盖 2（协议允许省略默认 ms=2）。score=majority 保持三榜准入及同分并列的 v1 公式，无 score 标记保持历史百分位公式。无分享参数默认 v2。新旧路径均保留；CSV 增补辅助分、实际对手数与公式标记。允许估算、历史与过期排除规则保持原样。

本 ADR 替代 ADR-0010 的默认准入与最终排序规则，不破坏其历史链接。
