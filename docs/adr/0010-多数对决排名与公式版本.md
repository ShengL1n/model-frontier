# ADR-0010：多数对决排名与公式版本

- 状态：已接受
- 日期：2026-10-19
- 授权：用户确认执行多数对决积分，并询问结合原始分；不引入无校准依据的混合权重。

## 决策

正式融合榜采用 Copeland 多数对决积分。AA、Vals、LiveBench 每榜各一票，比较同榜原始成绩，不跨榜相加。各模型对当前完整样本中的每个其他模型各比赛一次；单榜同分视为该榜平票，领先榜数多者赢下对决，领先榜数相同则对决平局。

积分 = 100 × (胜场 + 0.5 × 平场) / (完整样本数 − 1)。同积分同名次，不按原始分或名称打破实质并列；名称只用于稳定展示。不以多数关系作为 sort comparator，避免循环导致非传递排序。

仅三榜均有有效分的模型参加正式比赛。估算分受原有允许开关控制；历史与过期源排除在比赛样本确定前应用。缺榜不补零，不参加对决或前沿，原始成绩仍可展示。没有完整模型时所有积分为空；只有一个完整模型时因无对手仍不赋分、不赋正式名次，并明确解释。

多数关系可以循环，积分是全体对手上的比赛成绩；不保证每一场直接获胜都对应更高总名次，也不是正确率、能力比例或统计置信度。对比页同时展示两两票数、各榜胜负和原始分差，保留幅度信息；不将其加权混入主积分，不隐藏循环或同积分。

新模式固定三榜各一票和三榜完整覆盖，不提供权重或最低覆盖调节；旧模式控件仅用于旧链接复现，提供一键回到多数对决。

## 分享、导出与回滚

- 新公式显式编码 score=majority，未带公式参数的历史分享仍按旧排名百分位加权公式解码。应用无分享参数时默认新公式；本地旧偏好自动采用新公式，自定义历史权重仅保留为旧模式数据。
- 原 analyze 的默认旧计算路径保留，显式 scoring=majority 启用新公式；成本算法不改。
- 新公式忽略历史链接中 p/w/ms 对评分的影响，分享输出使用固定三榜等权、覆盖 3，避免无效参数误导。
- CSV 增补公式版本、胜平负和对手数，评分口径文本说明公式，保留原始分和数据时间。新旧链接都可直接复算。
- 回滚可打开无 score 参数的历史分享；保留旧计算函数路径，不销毁快照与偏好。

本 ADR 替代 ADR-0003/0009 关于默认评分公式的决策，旧决策保留为历史协议。
