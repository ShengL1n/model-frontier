# 配置证据、真实快照与数据质量

范围：配置差异摘要、真实变化快照、质量提示及主动排除。保留现有分数与权重算法，不引入覆盖奖励、可信分或虚构历史。

验收约定：
- 配置只识别源站明确披露的 effort / reasoning / fallback 标签。信息不足不推断一致；档位标签相同也不声称统一实验。
- 历史单独写入 `data/history.json`，现有 `snapshot.json` 和刷新设置保持兼容。用首次运行时的真实缓存建立起始快照，明确各来源获取时间；不推断此前变化。
- 最近保留 60 次有数据变化的独立快照，无变化不重复归档。失败来源保留旧行，不产生虚假的删除；行顺序变化不算变化。记录原始分、任务成本、token 价格、配置及状态变化；不把综合排名变化当成模型能力进步。
- 快照按源配置比较，不跨推理档位连接价格或分数趋势。源站新增收录不称作模型新发布。
- 质量控件允许排除历史配置、失败回退或超过 24 小时未成功获取的来源缓存。默认保持现有行为；估算开关沿用现有默认关闭。不按评测发布日期直接推断数据质量。
- 抓取成功时间与源站版本 / 发布标签分开显示，未知明确留空。排行榜、对比、前沿及稳定性共享分析排除规则，原始单榜视图保留独立过滤入口。
- 历史写入失败可见且不影响已获取缓存；保留文件后可回退旧程序，旧缓存格式不变。新程序再次启动时比较实际缓存续记变化。
- 验证迁移、重复启动、失败回退、去重、保留上限、配置判断、质量筛选、真实接口及窄屏交互。
