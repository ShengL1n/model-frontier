# 三榜融合工作台

本轮范围：将已有成本前沿工具扩展为模型评测工作台，继续使用 AA、Vals、LiveBench 的真实数据和后台 HTTP 定时更新。

验收：

- 默认进入总览，可查看综合能力领先模型、开放权重领先模型和三站覆盖情况。
- 融合排行榜不依赖成本是否披露；展示原始分、综合分、评分覆盖与成本，支持搜索、厂商及开放状态筛选、排序、导出。
- 单榜视图保留源配置及原始分，提供估算与历史配置开关，不将不同量纲原始分直接混排。
- 选择 2–4 个模型跨页对比，保存选择；展示同一评分口径下的相对分、原始分、原生任务成本、AA 速度和 LiveBench 分类能力。缺失不补零，不把榜单覆盖变为加分。
- 评分权重、覆盖门槛与估算设置由排行榜、对比和前沿共享；筛选只影响显示，不重新计算综合分。
- 保留帕累托、稳定性分析、详细配置追溯和刷新设置；不新增浏览器采集、不更改现有每小时设置。
- 桌面和窄屏无页面横向溢出；图表滚轮继续用于页面滚动。

本轮不引入：账号系统、外部托管、虚构历史趋势、额外榜单、许可证推断或部署成本估计。
